# 变更日志

版本号同步维护在两处：`tidywork-plugin/package.json` 与 `share-desktop/VERSION`。

## v3.37.0 · 笔记只留一个入口

- 笔记顶栏清空：`编辑 / 分屏 / 预览` 三个模式按钮与那排格式化按钮全部移除，只保留实时这一种写法。
- 随之收掉的能力：整屏源码编辑、markdown/纯文本左右分屏、只读预览；⌘E 不再切换预览。格式改走 Markdown 语法与编辑器自带快捷键。
- 加载失败兜底改为编辑器内重试：状态条出现「重试加载」，不必再切到别的模式。
- 旧本地存储里的 `tw-note-mode` 不再读取，切笔记也不会再被记到别的模式上。

## v3.36.0 · 笔记只留一种写法：实时

- 「即时」下线：块级点哪块编哪块的老写法移除，笔记默认进「实时」，也就是上一版的 Typora 模式（Vditor ir）。
- Typora 更名「实时」：入口、状态条、失败提示统一叫实时；内部 id 仍是 `typora`，不影响既有草稿与 localStorage。
- 老用户迁移：以前存过 `tw-note-mode=live` 的，自动落到「实时」；`编辑 / 分屏 / 预览` 三种保留，随时可切。
- 失败兜底改写：实时渲染加载不起来时，退回「源码编辑」而不是已经没有的「即时」，提示语同步改。

## v3.35.0 · 笔记多了一个"Typora 模式"

- 笔记编辑区新增第四种写法 `Typora`：单栏、点哪块编哪块、光标行进露源码、没有工具栏，交互照 Typora 来；原来的「即时 / 编辑 / 分屏 / 预览」全保留，切回去不丢东西。
- 引擎用 Vditor 的 `ir`（即时渲染）模式，资源随插件包分发（`lib/vendor/vditor`），由 `/tidywork-api/vendor/vditor` 读取，不依赖公网 CDN，断网可用。
- 只留一套主题：Vditor 自带的工具栏、面板、计数器、H1/H2 层级角标全部收掉；深浅色跟随宿主 `data-ds-dark-theme`，切主题自动重建实例。
- 补两个 Typora 手感开关：专注（只亮光标所在块）、打字机（光标保持在视口中线附近）。
- 图片粘贴走原来的 `/tidywork-api/attachments`，插到光标处；`todo:` / `meeting:` 内链在编辑器里点击仍跳对应面板；⌘S 保存、⌘E 回预览。
- 编辑方式记在 `localStorage`，换一篇笔记不用重新点。
- 视觉细节按 Typora 对齐：标题去掉层级角标与下横线；块级公式不套底色边框、上下不留半行空行；待办复选框换成插件自己的圆角描边风格。
- 体积代价：插件包增加约 7.6MB（lute 3.7MB 是硬成本），首次切到 Typora 模式时才加载，其余模式不受影响。


- 删除改为软删除：待办 / 会议 / 笔记先放进回收站（保留 7 天，上限 500 条），提示条上的「撤销」恢复原条目（原 id、笔记版本历史都在），不是重新造一条。
- 笔记彻底删除前只摘索引，正文文件与图片留到「彻底删除」时才清理，避免恢复后满地破图。
- 顶栏新增「⋯」菜单：导出 JSON 备份 / 导入备份… / 回收站；导出原来单独一个按钮，现在收进菜单，顶栏不再挤一排。
- 导入 JSON：只补不覆盖，同 id 跳过；单条字段非法只跳过该条，不整包失败。
- 新增 ⌘K 全局搜索（命令面板）：搜待办 / 会议 / 笔记，↑↓ 选择、回车打开，Esc 关闭；顶栏也放了「⌘K 搜索」按钮。因为宿主自己也占了 ⌘K，这里改成捕获阶段拦截后派发自定义事件。
- 工作台加「正在进行 / 下一场」提示条：会中显示「还有 X 分钟」，会前显示「还有 X 结束」；今天没会就不出现。
- 会议日视图把已结束的会议折叠成一行「已结束 N 场 展开/收起」，下午打开不再只剩一屏灰卡。
- 空看板给三步引导（加待办 / 建会议 / 连邮箱或导旧备份）。
- 修：日视图里「已结束」折叠用到的两个变量原本只在分支里声明，一进日视图就 ReferenceError 白屏。

## v3.33.2 · 不带出默认邮箱

- 邮箱设置弹窗不再预填上一次的账号：没保存过就是空，保存过才回填。
- 新增「清除已保存的账号」，一次抹掉账号与授权码，回到未配置状态，不必手改 `config.ini`。
- 代码与文档里的真实邮箱示例全部改成 `your_name@qq.com` 这类占位值。

## v3.33.1 · 顶栏合并为一个按钮

- 并排的「配置邮箱 / 邮箱设置」合成一个：未配置显示「配置邮箱」并直接开弹窗，配置后变成「扫描邮箱」。
- 扫描遇凭据问题（未配置 / 授权码失效 / 登录被拒）自动弹设置并说明原因，不用再找入口。
- 新增报错转译，把 IMAP 原始报错换成可读原因。

## v3.33.0 · 邮箱设置进插件

- 弹窗内直接填账号与授权码，写入数据目录 `mail/config.ini`（600 权限，不进安装包），保存时顺手跑一次引擎自检。
- 授权码可留空 = 暂停扫描；模板占位值（`your_name@qq.com` / `your_16_char_auth_code`）不再被判定为已配置。

## v3.32.0 · 邮箱进界面

- 顶栏加「扫描邮箱」：`POST /tidywork-api/mail/scan`，前端超时放宽到 180s，服务端扫描串行化。
- 待办与会议卡片显示「✉ 邮箱」来源标，悬停出邮件主题与发件人。
- 待确认的邮件邀请会议卡直接「接受 / 拒绝」（`/mail/rsvp`，按看板 id 反查 mailKey）。
- 旧数据（`mail_key` / `urgent|normal` / 中文回执标签）首次同步自动归一，不产生重复条目。

## v3.31.0 · 邮箱模块并入（后端）

- `tidywork-plugin/engine/` 收 QQ 邮箱引擎（IMAP / SMTP / CalDAV），标准库即可跑通扫描。
- 新增 5 个 Agent 工具：`tidywork_mail_scan / list / rsvp / done / add`。
- 邮件与日历抽出的事项投影进现有 `todos.json` / `meetings.json`，按 `mailKey` upsert，引擎侧消失即清理。
- 口径统一：优先级 `high/mid/low`（urgent→high、normal→mid）、会议独立 `rsvp`（`pending/confirmed/declined`）、`source.type = "mail"`。

## v3.30.2 · 新建工作项改名生效

- 客户端插件补 `sessions` 注入，修 `cannot get property "sessions" without inject`。
- 会话刚建时不在客户端目录，改为「等它出现在会话列表再改名，最多重试 6 次」；复用当天记录时也补改名。

## v3.30.1 · 新会话与新建工作项分开

- 「新会话」接管宿主 `ctx.uiWorkspace.startSession()`，开一个不属于任何工作区的普通会话。
- 「＋ 新建工作项」走 `connectWorkspace`，在 TidyWork 工作区建当天 `yyyy-mm-dd` 会话，同日复用。

## v3.30 · 安全与稳定性整改

1. `/tidywork-api` 写操作加来源校验（Host 白名单 + Origin 同源 + `Sec-Fetch-Site`；写请求必须 `application/json`），挡掉 CSRF。
2. 错误统一分码（400/403/404/409/413/415/500），字段超长明确 400，不再静默截断。
3. `view` 口径重做：`all` 返回全部，其余按 due 归一日期；客户端改成一次拉全量 + 本地筛选，切视图不闪重复行。
4. 会议时间结构化 `startTime/endTime`（兼容老 `time`+`duration`），状态按区间每分钟重算。
5. 笔记正文拆到 `notes/<id>.json`，`notes.json` 只留索引并自动迁移。
6. 附件按引用回收 + 32 位 hex 命名 + 私有缓存。
7. 新增 `/health`、`/export`。
8. 日志落 `logs/plugin.log`，按 1MB 轮转。
9. 删除改为 toast 撤销，去掉「点两次才算删」。
10. 键盘可达（焦点圈、按钮语义）、启动记住上次面板、英文 locale。
