# Q4 季度复盘与下季度规划

本季度围绕「把散落的工作收进一个看板」推进，三条主线：**工作台收敛**、**邮件进待办**、**笔记可写可查**。
下面按目标、数据、问题、下季度动作四段来写，尽量只留结论。

## 一、目标达成

| 目标 | 计划 | 实际 | 结论 |
| --- | --- | --- | --- |
| 工作台一屏可读 | 11 月中旬 | 11 月 24 日 | 达成，晚 10 天 |
| 邮件自动抽取 | 抽取待办与会议 | 已抽取，含 RSVP | 达成 |
| 笔记即时渲染 | 点哪块编哪块 | 已上线，块级编辑 | 部分达成 |
| 版本可回滚 | 20 个快照 | 已实现 | 达成 |

> 结论：主线都落地了，但「笔记」只做到能写，没做到**好写**。下季度的重点应该从这里挪到体验上。

## 二、几个关键数字

- 日均新建待办 4.2 条，其中 38% 来自邮件
- 笔记累计 126 篇，最长一篇 1.1 万字，打开耗时 240ms
- 版本快照触发率 17%，回滚 3 次，都是误删段落

## 三、暴露的问题

1. **长笔记打字发涩**
   - 每敲一个字整块重渲染，1 万字时明显掉帧
   - 中文输入法组字过程中偶发跳字
2. **表格只能看不能改**
   - 想加一行得切回源码模式，改完再切回来
3. **粘贴不干净**
   - 从飞书复制过来带一堆空行和全角空格

## 四、下季度动作

- [ ] 编辑器换成块级真渲染，先解决长文性能
- [ ] 表格单元格内直接编辑，Tab 走格
- [ ] 专注模式 / 打字机模式
- [x] 补齐 `- [ ]` 一键转待办（已上线）
- [ ] 图片粘贴上传与宽度拖拽

## 五、参考实现

本地跑一下对照组，脚本大致长这样：

```js
// 同一份 Markdown，两种渲染并排
const left  = mdToHtml(src, false);   // 现状：字符串拼 HTML

```
