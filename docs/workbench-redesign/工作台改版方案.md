# TidyWork 工作台改版方案（v3.8 提案 · 待确认）

> 目标：把「三张卡 + 三个空条 + 半屏留白」的现状，改成**一屏可操作的个人工作台**——打开就能看到今天要做什么、什么时候做、进度如何，并能直接勾掉一条待办。
> 原型：`工作台改版原型.html`（同目录，浏览器直接打开，可点可勾选）

---

## 一、现状诊断（基于 2026-11-08 实测截图）

| # | 问题 | 具体表现 |
|---|---|---|
| 1 | **上重下空，版面失衡** | 内容止于 y≈520，下方约 550px 纯空白，页面像被截断 |
| 2 | **卡片内信息过稀** | 「今日会议」卡 270px 高只放 1 行（14:00 产品评审会 3 人）；「今日待办」只有大数字 + 进度条 |
| 3 | **三个「查看全部 →」重复噪音** | 同一视觉权重出现 3 次，且都跳到其他页面，页面本身留不下东西 |
| 4 | **快捷入口是三条空条** | 无信息量，与卡片功能重复，占掉一整行高度 |
| 5 | **零操作能力** | 看到待办却不能在首页勾选完成；看到会议不能展开地点/参会人 |
| 6 | **缺"今天"的上下文** | 没有时间轴、没有逾期提醒（实际有 1 条已逾期：周五前完成周报，截止 11-06）、没有本周节奏 |
| 7 | **数据只呈现不复用** | 7 条待办、9 场会议、4 篇笔记只露出极小一部分，剩下的必须跳页才看得到 |

## 四、模块设计

### ① 今日日程（左栏，替换原「今日会议」卡）
- **时间轴**：09:00–18:00 整点刻度（3 列 grid：时间 / 轴线 / 内容），会议按起止时间定位成色块，块内显示标题 + 地点 + 人数。
- 今天的真实数据只有 1 场（14:00–15:00 产品评审会 · 会议室A · 3 人），因此**额外用"空档"承载信息**：把上午/下午无会议时段标为「可专注时段」，避免轴内出现大段空白。
- 点击色块 → 就地展开详情（起止时间、地点、参会人数），再点收起。
- 无会议日 → 空态文案「今天没有安排，适合安排一段深度工作」。

### ② 待办清单（左栏，替换原「今日待办」大数字卡）
- 默认显示**今天 + 明天 + 逾期**四类中的"近期"项；顶部 tab：今天 / 逾期 / 本周 / 全部（带数量角标）。
- 每行：勾选框 · 标题 · 优先级点（高=红 / 中=橙 / 低=灰）· 分类 · 截止（明天/今天/逾期 N 天）。
- **勾选即完成**：划线 + 行淡化，顶部计数、环形进度、tab 角标**同步重算**（数据口径：全部 7 条、已完成 4、完成率 57%）。
- 逾期项用红点 + 「逾期 2 天」字样（真实存在：周五前完成周报，due 11-06）。
- 底部「+ 添加待办」行内输入，回车即加（原型里真实入数组并重算）。

### ③ 本周节奏（底部横条，新增）
- 周一–周日 7 列，每列 = 星期 + 日期数字 + **待办点阵**（每条一个小方块，完成=实心蓝，未完=空心）+ 会议数徽标。
- 今天（11-08）列高亮（浅蓝底 + 蓝字）。
- hover 列 → 浮出「11月8日 · 待办 1 · 会议 1」。
- 作用：把"这周还剩多少"一眼看完，同时天然填满底部区域。

### ④ 本周进度（右栏，新增）
- SVG 环形 57%（4/7），中心大数字；侧边三行小指标：今日待办 1 · 本周完成 4 · 逾期 1。勾选后环形动一下（stroke 过渡）。
- 比原来的横向进度条信息量更大，且与待办完成联动。

### ⑤ 最近笔记（右栏，保留并加强）
- 4 篇真实笔记：DSH 架构调研笔记（今天 11:30）/ TidyWork 产品需求（昨天 18:00）/ Docker 部署备忘（11-01）/ 前端设计参考（10-30）。
- 每行两行式：标题 + 摘要 + 时间；hover 出现「打开」；点击 → 右侧浮出预览卡（标题、摘要、时间、"打开笔记 →"按钮），演示态 toast。

### ⑥ 快捷操作（右栏，替换原三个空条）
- 2×2 小按钮组（新建待办 / 新建会议 / 新建笔记 / 开始对话），图标 + 一行字，无大空白；点击走 toast（原型）或真实跳转（实施时调 `ctx.layout.selectPanel` / 唤起 DSH 会话）。

## 五、交互清单（原型里全部可点）

| 交互 | 反馈 |
|---|---|
| 勾选/取消待办 | 划线、计数与环形重算、tab 角标变化、底部进度条过渡 |
| 待办 tab 切换 | 列表按今天/逾期/本周/全部重渲染 |
| 行内新增待办（回车） | 新条目入列、计数更新 |
| 会议色块点击 | 就地展开/收起详情 |
| 周节奏列 hover | tooltip 显示当天待办/会议数 |
| 笔记点击 | 右侧预览浮层 + 打开按钮 |
| 新建类按钮 | toast「原型演示：实施后此处直接新建」 |
| 键盘可达 | 所有按钮/勾选框可 Tab 聚焦，有 focus-visible 描边 |

## 六、视觉规范（沿用现有品牌，不另起风格）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f7f8fa` | 页面底色 |
| `--card` | `#ffffff` | 卡片 |
| `--line` | `#e8eaef` | 分隔线 / 卡片描边 |
| `--ink` | `#1f2329` | 主文字 |
| `--ink-2` | `#646a73` | 次要文字 |
| `--ink-3` | `#8f959e` | 弱文字 / 时间 |
| `--brand` | `#3370ff` | 主色、完成态、今天高亮 |
| `--danger` | `#e5484d` | 高优先级 / 逾期 |
| `--warn` | `#ff8800` | 中优先级 |
| 圆角 | 卡片 12px · 小元素 8px | 与现有面板一致 |
| 字体 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` | 与 DSH 原生 UI 一致，不引第三方字体 |

原则：卡片不超过 6 个；不加渐变、不加毛玻璃、不加装饰性色块；颜色只用来编码优先级/完成/逾期三类信息；所有数字同源（7 / 4 / 57% / 1 / 9）由待办数组实时算出。

## 七、实施计划（确认后动插件代码）

1. 只改 `tidywork-plugin/lib/client.js` 中的 `HomePage`（约 1112 行起）与相关样式对象；服务端 `/tidywork-api` 不动（现有字段够用：`title/priority/category/due/done`、`date/time/duration/location/participants`）。
2. 需要新增的纯前端派生数据：逾期判断（`due` 为 `2026-11-06` 且未完成 → 逾期）、本周节奏（按 `due` 与 `date` 聚合 7 天）。不新增 API。
3. 交互挂在现有 API：勾选 → `PUT /tidywork-api/todos/:id`；行内新增 → `POST /tidywork-api/todos`；笔记点击 → `ctx.layout.selectPanel('tidywork-notes')` + 选中。
4. 改完 `node --check` → 重建容器 → 浏览器实测一屏无滚动留白、勾选与计数正确。
5. 方案文档追加 §13 v3.8 落地记录，截图存档。

## 八、需要你确认的 3 点

1. **布局**：采用「左日程+待办 / 右进度+笔记+快捷」两栏；窗口窄于 780px 自动单列。是否接受？
2. **优先级**：待办清单默认同时显示"今天 + 明天 + 逾期"（而不是只看今天）。是否接受？
3. **时间轴范围**：固定 09:00–18:00（会议超出范围时自动扩展到最早/最晚）。是否接受？
