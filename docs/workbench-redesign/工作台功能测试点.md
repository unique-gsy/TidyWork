# 工作台（v3.8）功能测试点

- 被测对象：DSH web 3080 的 TidyWork 工作台（插件 `tidywork-plugin/lib/client.js` 的 HomePage），以及其依赖的 `/tidywork-api` 与相邻面板。
- 测试环境：容器 `tidywork-assistant`（镜像 `tidywork-assistant:latest`，仅 3080），浏览器视口 789×811，普通浏览器窗口 + 应用内浏览器。
- 测试日：2026-11-09（周一）。真实数据：待办 7 条（完成 4 / 未完成 3，其中「周五前完成周报」到期 11-06 已逾期）、会议 9 场（今日 09:30–10:30 团队周会；本周另有 11-12 产品内测启动）、笔记 4 篇。
- 测试方法：浏览器逐项操作 + 读 DOM/控制台 + 数据落盘核对；边界与异常用临时构造数据（测完还原）。

## 判定口径

| 等级 | 含义 |
| --- | --- |
| P0 | 数据/口径错误，或主流程不可用 |
| P1 | 交互失效、状态不同步、可点无响应 |
| P2 | 视觉/文案/边界瑕疵，不影响主流程 |

### T1 日期与数据口径（P0）

| ID | 测试点 | 预期 |
