# TidyWork 插件 · DSH 桌面版安装包（v3.16）

给已经装好 **DeepSeek Harness 桌面版（macOS）** 的人用：装完侧边栏会多出 **工作台 / 待办 / 会议 / 笔记** 四块，工作台一屏看今天的日程与待办。

## 前置条件

1. 已安装 `DeepSeek Harness.app`（拖进 `/Applications` 即可）。
2. **至少打开过一次** DSH 桌面版——它会在 `~/.dsh/profiles/desktop` 里生成配置目录，安装脚本要往这里登记插件。
3. 不需要 Node、pnpm 或命令行环境，脚本借用应用自带的运行时。

## 安装

双击 **`安装.command`**。

- 若系统提示"无法打开，因为无法验证开发者"：在这两个 `.command` 文件上 **右键 → 打开**，选"仍要打开"即可。
- 也可以在"终端"里进入本目录执行：

```sh
sh install.sh
```

装完会自动重启一次 DSH 桌面版。左侧栏出现「工作台 / 待办 / 会议 / 笔记」即成功；若右侧还是 DSH 原界面，点侧栏最上面的「工作台」。

## 卸载

双击 **`卸载.command`**（或 `sh uninstall.sh`）。会移除插件登记与插件文件，**但不会删除你的待办/会议/笔记数据**（数据在 `~/.dsh/profiles/desktop/tidywork/`，重新安装后自动接上）。

## 安装脚本具体做了什么

透明起见，四件事：

1. 把插件复制到 `~/.dsh/plugins/tidywork-plugin`（固定位置，不留在下载目录里，避免被清理后失效）。
2. 再复制一份到 `~/.dsh/profiles/desktop/node_modules/@tidywork/dsh-plugin`（DSH 从这里加载插件）。
3. 备份 `~/.dsh/profiles/desktop/package.json`，再原地追加两处登记：
   - `dependencies` 里加 `"@tidywork/dsh-plugin": "file:~/.dsh/plugins/tidywork-plugin"`
   - `dsh.profile.bundles` 里追加 `"@tidywork/dsh-plugin"`
4. 重启 DSH 桌面版。

全程只碰 `~/.dsh` 下与 TidyWork 有关的路径，不修改 `DeepSeek Harness.app` 本体。

## 常见问题

- **侧栏没出现入口**：确认安装脚本最后打印了"完成"，然后彻底退出应用（⌘Q）再打开；仍不行就看 `~/.dsh/profiles/desktop/package.json` 里的 `dsh.profile.bundles` 是否包含 `@tidywork/dsh-plugin`。
- **升级**：用新版安装包再双击一次即可，覆盖安装；`package.json` 会自动再备份一份。
- **数据在哪**：`~/.dsh/profiles/desktop/tidywork/{todos,meetings,notes}.json`。
- **工作台顶栏的「＋ 新建工作项」**：点它回到 TidyWork 工作区里"今天"那个会话（没工作区就建、今天没会话就建），进去直接用自然语言交代待办/会议安排即可。
