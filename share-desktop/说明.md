# TidyWork 插件 · DSH 桌面版安装包（v3.25.1）

给已经装好 **DeepSeek Harness 桌面版** 的人用：装完侧边栏会多出 **工作台 / 待办 / 会议 / 笔记** 四块，工作台一屏看今天的日程与待办。

**v3.25.1 笔记列表按 Typora 逻辑重做**：行尾回车续同级新项（有序 +1、待办默认未勾选）；空项回车直接退出列表（嵌套项先退一级）；行中回车把后半段拆成新项并顺延；项首退格去掉列表标记、嵌套项先退一级；`Tab` / `Shift+Tab` 整行缩进与反缩进；有序编号按 Markdown 语义重算（同级顺延、子层独立、空行后重新起算），源码里的编号与渲染结果始终一致。`*` / `+` / `1)` / `1、` 等行首标记输入时自动规范成 `-` 或 `1.`。

**这一版回到 v3.25 的界面**：前端 `client.js` 用的是 v3.25 原文件，侧边栏顶部不注册 TidyWork 品牌，保持 DSH 原生的鲸鱼图标与 deepseek HARNESS 字样。宿主 `index.js` 保留后来补上的 `dateKey()`（按自然日命名今日会话不再报错）和 `/tidywork-api/ui` 资源路由（v3.25 前端不调用，留着不冲突）。

**v3.28 两块改动**：① 侧边栏顶部换成 TidyWork 自己的图标与「Tidy / Work」连体字标（不再用宿主鲸鱼图标，窗口标题与 favicon 仍不动）；② 四个面板的底色、边框、文字与强调色改用 DSH 原生设计变量，深浅色切换时与宿主界面同一套色，不再出现自配色和侧边栏不搭的情况。

**v3.23 侧边栏顶部恢复 DSH 原样**：不再把品牌改成蓝底「T」标 +「TidyWork」字样，侧边栏顶部、窗口标题与图标都回到 DeepSeek Harness 原本的样子；与 DSH 原生入口之间的分隔线保留。

**v3.22 待办的截止日改成日历选择**：新增/编辑待办的「截止」从四项下拉换成日历弹层，可直接点具体日期（今天/明天/本周/无期限的快捷项保留在弹层底部）；工作台底部「添加一条待办」也能先选日期再添加，不必再进编辑弹窗。

**v3.21 起首次安装是干净的空白面板**：不再写入示例待办、会议、笔记，装完就是 0 条，避免把示例数据当成自己的数据。

**v3.20 修了四个界面/写入问题**：① 会写入落在本实例（端口动态发布，不再写死 3080；Agent 先用 `cat ~/.dsh/profiles/desktop/tidywork/api-endpoint.txt` 取地址，或直接用生成的 `tw` 脚本）；② 收起侧边栏时顶栏给宿主浮层让位，不再压字；③ 今日日程时间轴按「视觉占位」分栏，30 分钟会议不再上下压块；④ 工作台回到侧边栏首位（工作台 → 待办 → 会议 → 笔记），「最近笔记」改为显示最新 4 篇。排会议时不再顺带自动新建笔记。

**v3.19 的笔记是「渲染即编辑」了**：默认「即时」模式，整篇按 Typora 那样排版渲染，光标落到哪一块，那一块就地变成 Markdown 源码，离开就渲染回去——点标题直接改标题、点正文直接改正文，回车自动分块，列表自动续写（有序号自动 +1、待办保留 `[ ]`），`Cmd/Ctrl+B/I` 加粗斜体、`Esc` 提交当前块，全程 900ms 自动保存，源码仍是唯一真源，老笔记零迁移。此外仍保留「编辑 / 分屏 / 预览」三态备用。桌面版还可以按住笔记页顶部那一条（标题所在的一行，一直到最右侧空白）拖动窗口。

**脚本按平台分成两套**，用你系统对应的那一套即可，插件本体（`plugin/`）共用：

```
mac-linux/   安装-mac.command  卸载-mac.command   install-mac.sh   uninstall-mac.sh
windows/     安装-windows.bat  卸载-windows.bat   install-windows.ps1  uninstall-windows.ps1
plugin/      插件本体
```

## 前置条件

1. 已安装 `DeepSeek Harness` 桌面版。
2. **至少打开过一次**——它会在自己的配置目录（mac/Linux `~/.dsh/profiles/desktop`，Windows `%USERPROFILE%\.dsh\profiles\desktop`）里生成配置文件，安装脚本要往这里登记插件。
3. 不需要 Node、pnpm，脚本借用应用自带的运行时。

## macOS

双击 `mac-linux/安装-mac.command`。

- 若提示"无法打开，因为无法验证开发者"：右键 → 打开 → 仍要打开。
- 或在终端里：`sh mac-linux/install-mac.sh`

卸载：双击 `mac-linux/卸载-mac.command`（或 `sh mac-linux/uninstall-mac.sh`）。

## Linux

命令行执行：

```bash
sh mac-linux/install-mac.sh
```

脚本会去 `~/Applications/*Harness*.AppImage`、`/opt/DeepSeek Harness/`、`~/.local/bin` 里找应用。找不到就用环境变量指定：

```bash
TW_APP=/path/to/DeepSeekHarness.AppImage sh mac-linux/install-mac.sh
```

卸载同理，换成 `uninstall-mac.sh`。

## Windows

双击 `windows/安装-windows.bat`。

- 会弹出命令行窗口跑脚本，结束后按回车关闭。
- 若 SmartScreen 拦下：点"更多信息 → 仍要运行"。
- 脚本以**当前用户**身份运行，不申请管理员权限（DSH 桌面版本身就是用户级安装）。
- 也可以在 PowerShell 里手动跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\install-windows.ps1
```

卸载：双击 `windows/卸载-windows.bat`。

## 安装脚本具体做了什么

两套逻辑一致，四件事：

1. 把插件复制到 `~/.dsh/plugins/tidywork-plugin`（固定位置，不留在下载目录，避免被清理后失效）。
2. 再复制一份到 DSH profile 的 `node_modules/@tidywork/dsh-plugin`。
3. 备份 profile 的 `package.json`，再原地追加两处登记：`dependencies` 加 `"@tidywork/dsh-plugin": "file:<第 1 步的路径>"`，`dsh.profile.bundles` 追加 `"@tidywork/dsh-plugin"`。
4. 重启 DSH 桌面版。

全程只碰 `.dsh` 下与 TidyWork 有关的路径，**不修改应用本体**，不需要管理员权限。

> Windows 上脚本按"用户级安装"的默认路径 `%LOCALAPPDATA%\Programs\DeepSeek Harness\` 找应用，找不到再查注册表里的安装位置。

## 常见问题

- **侧栏没出现入口**：确认脚本最后打印了"完成"；彻底退出应用（macOS ⌘Q／Windows 关掉所有窗口与托盘图标）再打开。仍不行就看 profile 的 `package.json`，`dsh.profile.bundles` 里应有 `@tidywork/dsh-plugin`。
- **升级**：用新版包再跑一次安装即可，覆盖安装，`package.json` 会自动再备份一份。
- **数据在哪**：profile 目录下的 `tidywork/{todos,meetings,notes}.json`。
- **工作台顶栏「＋ 新建工作项」**：点它回到 TidyWork 工作区里"今天"那个会话（没工作区就建、今天没会话就建），进去直接用自然语言交代待办/会议安排即可。
- **Windows / Linux 未实测**：macOS 上做过完整安装、重复安装、卸载验证；Windows 与 Linux 分支按同样逻辑与各自默认安装路径编写，若首次运行报错，把命令行提示发回即可定位。
